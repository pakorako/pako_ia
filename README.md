## 🤖 PAKO_IA

Bienvenue sur **PAKO_IA**, votre assistant virtuel intelligent, personnalisable et ultra-moderne ! 

Développée avec **Python** et **Streamlit**, cette application vous permet de discuter avec les modèles d'Intelligence Artificielle les plus puissants du marché (OpenRouter) ou d'utiliser des modèles locaux (Ollama) en toute confidentialité.

### Installez les dépendances
